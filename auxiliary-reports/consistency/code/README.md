# Consistency Code & Replication Package

This directory contains the code, caches, reference outputs, and runner script to reproduce every numerical result and figure data in the auxiliary report:
**"When Does Answer Diversity Mean Disagreement? Possible Worlds and the Scope of Semantic Entropy"** ([`../report/consistency_report.pdf`](../report/consistency_report.pdf)).

## Directory Structure

```
code/
├── src/               # Python source scripts
├── cache/             # Precomputed generation and NLI matrices (.jsonl and .npz)
├── results/           # Intermediate and generated CSV tables and run logs
├── expected_outputs/  # Reference logs for verification via --check
├── run_all.sh         # Master replication runner
└── requirements.txt    # Pinned Python dependencies
```

- **`src/`**: Implementation of event structures, possible worlds, conflation analysis, and bootstrap intervals:
  - `event_structure.py`: Finite event structures, maximal independent sets, homotopy types of independence complexes, and numerical check of Proposition 3 (Table 2).
  - `triviaqa_worlds.py`: Evaluation of possible worlds and semantic entropy on TriviaQA (Tables 4 and 5).
  - `domain_conflict.py`: Cross-domain conflation rate and evidence-swap experiments (Table 6).
  - `conflation_intervention.py`: Entity-to-sentence intervention experiment (Table 7).
  - `incoherent_support.py`: Support cone consistency and active contradiction on PublicHearingBR (Table 8).
  - `intervals.py`: Wilson and clustered bootstrap intervals across all experiments.
  - `common.py`, `finite_space.py`, `triviaqa_collect.py`, `llm.py`, `nli_runner.py`: Reusable utilities, NLI wrapper, and helper modules.
- **`cache/`**: Persisted artifacts (~2.3 MB) containing LLM generations and mDeBERTa NLI matrices (`f11_triviaqa.jsonl`, `f12_nli.npz`, `h3_nli.npz`, `h5_longas.jsonl`, `h5_nli.npz`, `f4_geracoes.jsonl`, `f7_intervencao.jsonl`, `f2_matrizes.npz`, `h4_nli.npz`). These allow all analyses to run completely offline without GPU or API access.
- **`results/`**: Shipped base tables (`opinions_meta.csv`, `incoherent_support.csv`), output tables generated by the scripts, and execution logs (`results/logs/<script>.txt`).
- **`expected_outputs/`**: Shipped reference terminal outputs used to ensure exact bitwise reproduction of all report numbers.

## Requirements & Environment

The analysis runs on CPU in ~1–2 minutes using Python 3.11 with pinned packages:

```bash
pip install -r requirements.txt
```
*(Dependencies: `numpy==2.4.6`, `pandas==3.0.5`, `scipy==1.17.1`, `requests==2.34.2`)*

> [!NOTE]
> Deep learning dependencies (`torch`, `transformers`, `datasets`) are commented out in `requirements.txt` and are only needed if you explicitly delete a cache file to recompute NLI matrices from scratch.

## How to Run & Reproduce

All commands are executed from this directory:

```bash
./run_all.sh [--check] [--pdf]
```

| Command | What it does | Requirements |
|---|---|---|
| `./run_all.sh` | Runs all analyses offline from `cache/` and logs to `results/logs/` | Standard CPU (~1–2 min) |
| `./run_all.sh --check` | Runs all analyses and diffs every log against `expected_outputs/` (exits with code 1 on discrepancy) | Standard CPU |
| `./run_all.sh --pdf` | Runs analyses and compiles `../report/consistency_report.pdf` | TeX Live (`pdflatex` + `bibtex`) |

> [!IMPORTANT]
> **Dataset Dependency for Table 8:** `incoherent_support.py` runs only if the processed PublicHearingBR corpus exists at `dataset/phrasal_data/` (or via `export PHBR_DATA=/path/to/dataset`). If absent, `run_all.sh` gracefully skips recomputing it and `intervals.py` uses the precomputed `results/incoherent_support.csv`.
